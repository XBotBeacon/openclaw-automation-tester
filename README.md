# OpenClaw Setup

## Setup
1. Copy `config.template.json` to `config.json`
2. Replace `REPLACE_WITH_YOUR_OPENAI_KEY` with your actual OpenAI API key
3. Replace `REPLACE_WITH_YOUR_BOT_TOKEN` with your Telegram bot token
4. Run `cp config.json ~/.openclaw/openclaw.json`
5. Run `openclaw gateway run`
